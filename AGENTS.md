# Правила работы над проектом

- Каждое обращение к пользователю начинать с имени: «Дима».
- После выполнения этапа или части этапа всегда отдельно перечислять, что ещё осталось сделать.
- В процессе разработки поддерживать актуальными `ready.md` и `todo.md`.
- После каждой production-сборки Docker: только после успешного переключения контейнеров и healthcheck удалять неиспользуемые старые образы. Не удалять образы работающих контейнеров, PostgreSQL, радио или сторонних сервисов. Build cache сохранять для следующих сборок; удалять его только при нехватке места и после проверки, что есть запас RAM/swap. Перед тяжёлой сборкой проверять свободное место и память.
